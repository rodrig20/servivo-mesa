Sistema de Atendimento

Esta aplicação foi desenvolvida com o intuito de simplificar a forma de lidar com diversos pedidos de clientes. Além disso, fornece algumas configurações para que a experiência de todos seja a melhor.

Essas maravilhas são realizadas através de um site que permite que cada Atendente recolha os pedidos de todos os Clientes e os envie para os pontos corretos. Posteriormente, esses pedidos são realizados pela cozinha e os respetivos Atendentes são informados de que os mesmos estão prontos para serem entregues aos Clientes.
